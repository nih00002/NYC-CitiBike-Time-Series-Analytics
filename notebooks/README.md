# Thesis Practical Notebook

This folder contains the cleaned archival notebook developed for the 2021 M.Sc. thesis:

**Improvement of Bike Sharing Disposition by Business Analytics and Open Data Usage**

The practical work focuses on NYC Citi Bike operational analytics, time-series forecasting, weather integration, station-level analysis, and preparation of results for business-intelligence visualization.

## Notebook

`CitiBike_Time_Series_Analytics.ipynb`

Main areas covered:

- 2020 NYC Citi Bike trip-data preparation
- Seasonal and station-level exploratory analysis
- Relative-humidity integration
- Daily demand and trip-duration aggregation
- Augmented Dickey-Fuller stationarity testing
- ACF and PACF analysis
- ARIMA forecasting
- Auto-ARIMA model selection
- SARIMAX forecasting with relative humidity
- Prophet forecasting
- Operational inspection analytics
- Monthly bike-demand forecasting
- Overall daily bike-usage forecasting
- Data preparation for Power BI

## Reproducibility Note

This notebook is a cleaned archival version of work completed in 2021.

Some Python libraries and APIs used in the original implementation have since changed or been deprecated. A modern environment may therefore require small compatibility updates before every cell can be rerun.

The original datasets are not included in this repository.
