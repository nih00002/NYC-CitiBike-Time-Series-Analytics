# Selected Results

This folder contains selected analytical figures from the time-series analysis conducted for the 2021 M.Sc. thesis project.

The figures include time-series diagnostics, station-level forecasts, monthly bike-demand analysis, and overall bike-usage forecasts using ARIMA, Auto-ARIMA, and Prophet.

These figures are preserved outputs from the original 2021 analytical workflow and have not been recomputed to produce newer results.
