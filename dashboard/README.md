# Power BI Results

This folder contains selected Power BI outputs preserved from the 2021 M.Sc. thesis.

## Dashboard Outputs

- `powerbi_station_dashboard.png` — Station-based dashboard for tracking daily bike usage, station activity, relative humidity, geographic locations, and forecast behavior.
- `powerbi_weekday_forecast.png` — Weekday-filtered bike-usage analysis and forecast using Power BI's exponential-smoothing forecasting functionality.

These images were extracted from the original thesis PDF so that the Business Intelligence component of the project can be reviewed directly on GitHub.

The original analytical work was completed in 2021.
