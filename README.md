# Selected Results

This folder contains selected analytical figures extracted from the cleaned archival notebook for the 2021 M.Sc. thesis project.

The figures are original outputs from the practical analysis and are provided to make the principal time-series experiments easier to review without opening the full notebook.

## Figures

- `01_acf_pacf_trip_duration.png` — ACF/PACF diagnostics for the trip-duration time series.
- `02_acf_pacf_stationary_trip_duration.png` — ACF/PACF diagnostics after stationarity transformation.
- `03_arima_station_forecast.png` — Station-level ARIMA forecasting output.
- `04_auto_arima_station_forecast.png` — Station-level Auto-ARIMA forecasting output.
- `05_prophet_station_forecast.png` — Station-level Prophet forecasting output.
- `06_monthly_bike_demand_2020.png` — 2020 monthly bike-demand visualization.
- `07_auto_arima_monthly_demand_forecast.png` — Auto-ARIMA monthly-demand forecasting output.
- `08_prophet_monthly_demand_forecast.png` — Prophet monthly-demand forecasting output.
- `09_auto_arima_overall_usage_forecast.png` — Auto-ARIMA overall bike-usage forecasting output.
- `10_prophet_overall_usage_forecast.png` — Prophet overall bike-usage forecasting output.
- `11_arima_overall_usage_forecast.png` — ARIMA overall bike-usage forecasting output.

> These are preserved outputs from the original 2021 analytical workflow. They have not been recomputed or altered to produce newer performance results.
